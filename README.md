 🌦️ Smart Weather Planner

A responsive weather and travel planner built using **HTML, CSS, and JavaScript**. The application provides real-time weather information and suggests nearby tourist attractions for the entered city.

## ✨ Features

- 🌍 Search weather by city
- 🌡️ Real-time temperature, humidity, and wind speed
- ☁️ Weather condition with icons
- 🏞️ Nearby tourist place suggestions
- 📱 Responsive design
- ⚡ Fast and easy to use

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- OpenWeather API
- REST Countries API (Optional)
